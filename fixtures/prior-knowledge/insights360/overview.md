# Insights360 — overview (sample prior knowledge for the offline suite)

Insights360 is post-call call analytics for contact centres. It takes recordings from the existing phone system, transcribes and analyses each call after it ends, and shows QA scores, agent performance and risk flags in a web app. It is not real-time and it does not record calls itself.

It is hosted in the EU. Results appear within about an hour of a call ending. Roles are admin, supervisor and viewer.
